# ai-driven-dev-demo

AI 駆動開発（on the loop 型）の進め方を紹介するためのデモリポジトリです。

人と AI で仕様を詰め、実装とレビューは AI が行う流れで、オリジナルの落ちものパズルを作ります。その過程と紹介用のスライドも、このリポジトリに置きます。

## 遊ぶ

https://kotaroyatabe0235.github.io/ai-driven-dev-demo/game/

パソコンのブラウザで開き、キーボードで遊びます。ページを開くとすぐ始まります。手元で開くときは `game/index.html` をブラウザで開けば動きます（ビルドは要りません）。

| キー | 操作 |
| --- | --- |
| ← → | 左右に動かす |
| ↑ | 右に回す |
| Z | 左に回す |
| ↓ | 1 マス落とす（1 マスにつき 1 点） |
| スペース | 一気に落とす（1 マスにつき 2 点） |
| Enter | やり直し |

- 横の列がそろうと消えます。消した列数に、レベルをかけた点が入ります（1・2・3 列で 100・300・600）。
- 10 列消すごとにレベルが上がり、落ちる速さが増します。
- 積み上がってブロックが出せなくなると終局です。最高点は残りません。

## 中身

| 場所 | 中身 |
| --- | --- |
| `spec.md` | 仕様。人が決めたことと、AI が決めたことを分けて書いています |
| `game/` | ゲーム本体。規則（`rules.js`）、キー割り当て（`keys.js`）、画面（`index.html`・`style.css`・`main.js`） |
| `test/` | 自動テスト |
| `slides/` | 紹介用のスライド（https://kotaroyatabe0235.github.io/ai-driven-dev-demo/slides/） |
| `.github/workflows/` | PR ごとにテストを走らせる設定 |

## テスト

Node.js が入っていれば、次で自動テストを走らせられます。npm のパッケージは要りません。

```
node --test
```

## コミット前の確認

公開リポジトリのため、`.githooks/` のフックで個人情報・認証情報を検査しています。clone したら次を実行してください。

```
git config core.hooksPath .githooks
```
